# 🏎️ RaceFocus: F1 Pomodoro Timer

A beautifully designed, local-first Pomodoro timer built specifically for Formula 1 fans. Manage your focus sessions like a race: configure your driver details, select your tire compound, wait for the five red lights to go out, and start logging laps while your engine roars! 

## ✨ Features
- **Immersive F1 Experience**: Authentic 5-red-lights countdown sequence complete with synthesized engine launch audio and gear shifts.
- **Customizable Strategy**: Configure your "race" (focus duration) and your "pit stop" (break duration). Pit stops default to 3 minutes!
- **Dynamic Race Track UI**: Watch your car navigate a minimalist race track layout during your focus blocks, and disappear into the pits during your breaks.
- **Local-First Architecture**: All your stats, lap counts, and total focus time are saved locally in your browser. No databases, no logins, no cloud dependencies.
- **Race Engineer Messages**: Receive encouraging radio messages from your virtual race engineer as you hit focus milestones.

## 🚀 How to Run Locally

You can easily run this web application on your own computer.

### Prerequisites
- You must have [Node.js](https://nodejs.org/) installed (version 18 or higher is recommended).
- Git (optional, to clone the repository).

### Installation & Setup

1. **Download the code**: Clone this repository or download the source code folder to your local machine.
2. **Open Terminal**: Open a terminal or command prompt in the root folder of the project (the folder containing `package.json`).
3. **Install Dependencies**: Run the following command to download all required packages:
   ```bash
   npm install
   ```
4. **Start the Development Server**: Once installation is complete, start the app with:
   ```bash
   npm run dev
   ```
5. **Open the App**: Open your web browser and navigate to `http://localhost:3000`.
